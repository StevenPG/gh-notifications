# Security

The server binds to `127.0.0.1` only and reuses your `gh` CLI login; it never
stores or transmits your token. It is meant to run on your own machine, so do
not expose it to a network.

To report a vulnerability, please use GitHub's private
[security advisories](https://github.com/StevenPG/gh-notifications/security/advisories/new)
rather than a public issue.
